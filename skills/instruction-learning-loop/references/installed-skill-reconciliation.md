# Vendor Skill Boundaries

Use selected domain skills for their APIs, generators, formats, and platform
contracts. User scope and existing authorization control their methodology.
Do not load unrelated references or add approval checkpoints to authorized work.

## Generic Methodology

The default kit disables Superpowers methodology loading. Root agreements and
the delivery skill cover ordinary planning, delegation, debugging, and focused
verification. If explicitly using another process skill, apply useful methods
without repeated approvals, per-task review quotas, or mandatory documentation.

## Application Toolkits

Preserve source discovery, writable-target checks, dependency mapping,
compatibility, data binding, and runtime readback. Discover dependencies needed
for the named workflow; discovery does not authorize migrating every reachable
page or adding unrelated sections.

Existing authorization satisfies an approval stage only when its exact source,
target, package, scope, and effect are established. Resolve genuinely missing
access, registration, or product decisions before their writes. Never fabricate
approval, suppress validator failures, or silently register environments.

Size generated analytics, dashboards, and supporting features to the requested
workflow. A quota in a runbook does not justify additional functionality.
Keep executable platform preconditions distinct from methodology.

## Design Tools

Use remote canvas or generation workflows when they serve the requested outcome.
A broad design trigger does not authorize repository upload, extra generations,
or spending. Follow explicit tool choices and preserve native design contracts.

Use supported no-open options unless the user requests the visible interactive
workflow. Never hide or minimize the user's existing window as a workaround.
A design-only task ends at the requested design; authorized implementation
continues through appropriate artifact or runtime verification.

## Maintenance

Keep project and machine details in their owning local sources. Shared examples
remain generic across devices. Routing belongs to the delegation topology and
registered profiles.

If a selected skill still forces a pause or divergence, link and quote its exact
instruction and explain the conflict. Technical incompatibility remains a real
blocker; a methodology preference cannot create new authority requirements.
