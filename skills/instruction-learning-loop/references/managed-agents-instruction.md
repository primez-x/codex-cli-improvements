## Instruction Learning

* Use `instruction-learning-loop` when source-backed evidence warrants a durable correction. Apply an authorized correction to the narrowest user-owned source and relevant consumers; for read-only or out-of-scope work, propose only. Do not edit vendor caches as durable source or claim installed/runtime alignment without checking it.
* Agent-discovered errors qualify for durable learning only after root cause is established and the fix is freshly verified. Expected probes, test-first failures, and one-off failures do not qualify.
* For user-reported errors, distinguish technical verification from user-observed confirmation and report both truthfully. Confirmation is not a completion gate and does not force an instruction edit after a verified fix.
* Change memory only when the user explicitly requests it.
